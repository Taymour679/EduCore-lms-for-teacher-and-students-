# 🎓 EduCore – Learning Management System (LMS)

**EduCore** is a modern Learning Management System designed to connect teachers, students, and school administrators through one centralized educational platform.

Our goal is to simplify school management, improve communication, and create a better digital learning experience.

## 🚀 Features

- **Student Dashboard** – Access courses, assignments, grades, and learning resources.
- **Teacher Dashboard** – Manage classes, create assignments, track student progress, and organize learning materials.
- **School Admin Dashboard** – Manage teachers, students, classes, and school activities.
- **Platform Owner Dashboard** – Manage and oversee the platform.
- **Authentication & User Roles** – Role-based access for different types of users.
- **Modern Interface** – Clean, intuitive, and desktop-first design.

## 🛠️ Technologies Used

- Next.js
- React
- TypeScript
- Tailwind CSS
- Prisma ORM
- PostgreSQL (Neon)

## 📦 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Taymour679/EduCore-lms-for-teacher-and-students-.git
```

### 2. Navigate to the project

```bash
cd EduCore-lms-for-teacher-and-students-
```

### 3. Install dependencies

```bash
npm install
```

### 4. Configure environment variables

Create a `.env` file in the root directory and configure the required environment variables.

Never upload your `.env` file or database credentials to GitHub.

### 5. Set up Prisma

```bash
npx prisma generate
npx prisma db push
```

### 6. Start the development server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
