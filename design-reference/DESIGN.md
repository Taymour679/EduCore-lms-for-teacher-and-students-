# EduCore Clarity

Visual source of truth for the EduCore product UI. The Stitch zip archives were not present in the workspace. These tokens combine the written EduCore Clarity spec with the exported screens.

## Colour

| Token | Value | Use |
| --- | --- | --- |
| canvas | `#F8F9FC` | App background |
| surface | `#FFFFFF` | Cards |
| sidebar | `#0F1535` | Desktop sidebar |
| ink | `#0F1535` | Primary text |
| muted | `#64748B` | Secondary text |
| line | `rgba(226,232,240,0.8)` | Card border |
| primary | `#5B4BDB` | Actions, active nav |
| primary-hover | `#4B3DC4` | Hover |
| info | `#2563EB` | Links, information |
| success | `#059669` | Graded, positive |
| warning | `#D97706` | Due soon |
| danger | `#DC2626` | Overdue, errors, destructive |

## Shape

- Cards: 16px radius, 1px border, soft shadow
- Buttons, inputs, chips: 8px radius
- Minimum touch target: 44px

## Type

Inter, regular body 14–16px, page titles 28–32px semibold. WCAG AA contrast on canvas and sidebar.

## Navigation

Desktop: persistent navy sidebar plus top bar. The "no persistent sidebar" note in early exports is overridden by the screens. Mobile: hamburger drawer and, for students, a bottom nav (Home, Homework, Progress, AI Study).
